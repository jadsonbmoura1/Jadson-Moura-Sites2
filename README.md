# VOLT Store — e-commerce demonstrativo

Landing page moderna para uma loja de eletrônicos, criada com HTML, CSS e JavaScript puro.

## Como executar
Abra `index.html` no navegador ou publique os três arquivos na raiz de um repositório GitHub.

## Publicar com GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js` (e este README).
3. Vá a **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`, e salve.
5. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

## O que já funciona
- Layout responsivo para desktop e celular.
- Filtro por categoria e busca de produtos.
- Carrinho com quantidade, remoção e subtotal, salvo no `localStorage`.
- Favoritos visuais.
- Formulário de newsletter demonstrativo.
- CTAs e seções focadas em conversão.

## Antes de vender de verdade
Este projeto é um **front-end demonstrativo**. Os produtos, preços, avaliações, frete e promoções são exemplos e devem ser revisados. O checkout ainda não processa pagamentos nem cria pedidos. Para vender de verdade, integre uma plataforma/checkout (por exemplo, Shopify, WooCommerce, Mercado Pago ou Stripe), configure estoque, frete, política de troca, privacidade, termos e atendimento. As imagens são carregadas de URLs externas do Unsplash.
